## Sections

- **About** — Introduction and currently learning card
- **Skills** — Table and cards showing HTML, CSS, Java, Python
- **Projects** — Portfolio website, Delivery Management System, Table practice
- **Contact** — Contact links and message form

## Technologies Used

- HTML5 — semantic tags, forms, tables, hyperlinks, images, lists
- CSS3 — box model, float layout, selectors, animations, media queries
- No JavaScript used

## How to Run

1. Download all 4 files into one folder
2. Open `index.html` in any web browser
3. No server or installation needed
